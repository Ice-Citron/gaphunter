GapHunter

Find where your benchmark stopped before the hidden eval does.

Sample → run → map → report. GapHunter samples the hole offset (dx, dy, yaw) from the benchmark's box and a wider deployment box, runs the policy, and maps where it fails. Task: MuJoCo UR5e peg-in-hole, 20 mm square peg, 21 mm hole. Success: depth ≥ 30 mm, lateral error < 1 mm.

How it works

  1. Sample30 points in the benchmark's box, 600 Sobol points over the deployment box (dx -0.20…+0.20 m, dy -0.20…+0.20 m, yaw -90…+90°).
  2. Runeach point through run_trial(params) → TrialResult: peg-in-hole, UR5e.
  3. Mapsuccess rate per cell, with the benchmark's box drawn on top.
  4. Reportthe benchmark covers 2.1% of the domain; the worst band is dx +0.13…+0.20 at 0% (n=101).
  1. The goal of any robotics firm is to deploy a system with four-nines reliability as cheaply as possible.
  2. Each step-up in the reliability regime — 90%, 99%, 99.9%, 99.99% — is equally difficult.
